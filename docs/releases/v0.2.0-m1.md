# SystemScope v0.2.0-m1: RV32I Architectural CPU

M1 runs bare-metal RV32I machine code on the M0 deterministic simulation kernel. The
design, the acceptance tests, and the exit criteria with their evidence are in
[m1-design.md](../m1-design.md) (§10, §11). This is an early milestone, not a usable
simulator of real hardware.

## What shipped

- **`contracts`** (pinned at `4d6e912`, which gets the same milestone tag):
  - the `mem.v1` memory protocol, which can report an access fault;
  - the compatibility id `"0.0.0"`, decoupled from the crate version (§4.5).

  `mem.v0` is frozen, byte-identical to `v0.1.0-m0`.
- **`systemscope-rv32i`:**
  - all 40 RV32I (version 2.1) instructions at F2 architectural fidelity, with no pipeline;
  - every fetch and data access goes through the bus;
  - architectural state changes only at commit;
  - the nine trap causes of §6 end the run at the execution-environment boundary.
- **`systemscope-platform`:**
  - `AddressBus`: fixed memory map, never splits a request, access faults for unmapped or crossing requests;
  - sparse, canonical `Ram`;
  - `SimpleUart`: a TX byte register and an always-ready STATUS, strict decoding, not a 16550.
- **`systemscope-elf`:** a host-side loader for a checked ELF32 subset:
  - little-endian `EM_RISCV` `ET_EXEC`;
  - `PT_LOAD` only, with `p_vaddr == p_paddr`;
  - segments inside RAM and non-overlapping;
  - an aligned entry inside a segment.

  `image_hash` is the ELF's BLAKE3.
- **`m1-reference`:**

  | Component | Configuration |
  |---|---|
  | `soc.cpu0` | 100 MHz clock |
  | `soc.bus` | memory map below |
  | `soc.ram` | 16 MiB at `0x8000_0000` |
  | `soc.uart` | 8 bytes at `0x1000_0000` |

  Every link has one-cycle latency, and the instruction limit is 10,000,000.
- **Determinism:** every M0 guarantee now holds for ELF runs too:
  - StateDigest, ExecutionDigest, and TraceDigest;
  - checkpoint and restore from any event;
  - a portable snapshot `tests/golden/m1-reference.mid.snap`;
  - observation invariance.

  The committed golden file is `tests/golden/m1-reference.json`. It covers `hello` and the 40 `rv32ui` tests.
- **Test programs:**
  - the SystemScope `riscv-tests` environment and 40 committed `rv32ui` fixtures;
  - `hello.elf`, which prints exactly `Hello, SystemScope!\n`;
  - a deterministic RV32I program generator;
  - misaligned-access trap programs;
  - the committed ACT4 RV32I corpus.

  Every committed ELF is pinned by a manifest.

- **External validation:**
  - The rv32ui fixtures are rebuilt in CI with the pinned toolchain and must be byte-identical.

## Known limitations

- **ISA:** RV32I only.
  - No Zicsr, Zifencei, or privileged architecture: no CSRs, privilege modes, trap handlers, or `mret`.
  - No interrupts and no M, A, F, D, or C extensions.
  - A trap ends the run and is reported to the execution environment; nothing handles it.
- **Memory:**
  - Misaligned loads and stores trap; they are never emulated.
  - One hart, one outstanding memory operation.
  - No caches, pipeline, or MMU.
- **Timing:** cycle counts and tick values carry no performance meaning.
- **UART:** TX only, with no receive path, FIFO, baud rate, or interrupts.
- **Loader:** a strict subset of ELF32.
  - Rejected: PIE, relocatable, and dynamic images, ELF64, big-endian files, and images whose load and virtual addresses differ.
  - Section headers and symbols are not read.
- **Spike differential:**
  - It compares each program up to its `tohost` stores or its first trap.
  - Its trap coverage is load and store misalignment only.
  - Programs that use the UART, such as `hello.elf`, are not compared, because Spike's device map differs.
  - Spike runs only on Linux.
- **ACT4 corpus:** 39 unprivileged RV32I tests; privileged tests are disabled. Regenerating the corpus needs Linux x86_64.
- **Golden digests:** the nightly random-seed programs have none, as in M0.
- **Mutation testing:** the exploratory nightly mutation run in `contracts` (not a gate) reports 14 missed and 1 timed-out mutants out of 194.
  - All of them are in code from M0: `Display` implementations, `Decoder::remaining`, `Component::inspect` and `Observer::on_trace` defaults, and time helpers.
  - None is in `mem.v1`.
  - M1 does not change `contracts` beyond `mem.v1` and the compatibility id, so they remain open.
